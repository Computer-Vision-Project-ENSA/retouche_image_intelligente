# Data Preprocessing – Intelligent Image Retouching

## Overview

This module handles dataset collection for the **Intelligent Image Retouching** project, a Computer Vision system designed to enhance image quality automatically.

The dataset is sourced from the **Google HDR+ Dataset**, which provides RAW image bursts and processed HDR+ images.

The objective is to collect paired images for training and evaluating image enhancement models.

## Dataset

**Source:** [Google HDR+ Dataset](https://hdrplusdata.org/dataset.html)

The dataset contains:
- RAW images (`.dng`) captured before HDR+ processing.
- Processed images (`final.jpg`) generated by the HDR+ pipeline.
- Multiple RAW frames per photographic burst.

For the initial experiment, the dataset is limited to 20 image bursts.

The `input.dng` files are downloaded by the RAW collection script when matching source files are available.

## Scripts

### 1. `uploadImages.py`

Connects anonymously to Google Cloud Storage and downloads processed HDR+ images.

**Features:**
- Connects to the public Google HDR+ storage bucket.
- Lists available HDR+ images.
- Downloads a configurable number of processed images.
- Organizes images by burst identifier.
- Skips files that have already been downloaded.

### 2. `download_raw.py`

Retrieves the corresponding RAW images for previously downloaded HDR+ images.

**Features:**
- Identifies existing image burst directories.
- Searches the Google HDR+ bucket for matching RAW files.
- Downloads one RAW image per matching burst.
- Preserves the existing dataset structure.
- Avoids downloading files that already exist.

## Installation

Install the required dependencies:

```bash
pip install google-cloud-storage tqdm
```

## Usage

Run the scripts from the project root directory.

**Step 1 – Download processed images**

```bash
python data-preprocessing/uploadImages.py
```

**Step 2 – Download matching RAW images**

```bash
python data-preprocessing/download_raw.py
```

Both scripts use the following dataset directory:

```text
data/hdrplus/
```
